# Airline Reservation System (C++)

## Description
This is a console-based Airline Reservation System developed in C++ using Object-Oriented Programming (OOP).

## Features
- Flight Management
- Passenger Management
- Ticket Booking System
- Ticket Cancellation
- Exception Handling
- File Handling
- Report Generation

## How to Run
1. Open project in Dev-C++ / CodeBlocks
2. Compile all .cpp files together
3. Run main.cpp

## Concepts Used
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
